# Myo live UX friction log

**Journey:** First-time client requests a dog walk for Cooper, then sees Myomi’s completed visit and diary update. **Setup:** Separate clean Node servers and databases for desktop Chromium at 1440 × 900 and touch-emulated Chromium at 390 × 844. Both runs completed the same 26 captured states. The client began on the homepage. A separate browser session acted as Myomi. The test used live forms, navigation, server writes, and page reloads.

The three-second check is an assessment of what’s visible on arrival. All pixel positions are measured from the top of the viewport before scrolling unless specified. No horizontal page overflow or uncaught browser error appeared in the captured states. The two HTTP 400 responses per run came from intentionally submitting a short password and reviewing a booking without a pet.

Paths below are relative to the app repository.
